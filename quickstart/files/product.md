# Company Assistant Overview

This app is an internal knowledge assistant for a growing software company.

Employees ask questions in chat instead of hunting through Notion, Slack threads, onboarding docs, and old planning notes.

Example questions:

- How do I request access to a production dashboard?
- What is the expense policy for customer travel?
- Where should I document a customer escalation?
- What should a new engineer do in their first week?

The goal is simple: faster answers, fewer repeated Slack questions, and a lightweight memory layer for company-specific context.
